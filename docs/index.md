# linear

`linear` is a WireCat command-line tool for the terminal, for scripts and for AI agents.
It copies a Linear workspace's teams, users, workflow states, labels, projects, issues and comments into the local
store (`sync`), lists and shows them offline (`issues`, `projects`, `teams`…), and its `api` group reaches Linear, one
command per operation of Linear's GraphQL schema.

It has the commands every WireCat CLI shares: `doctor`, `commands`, `config`, `skill`, `mcp`, `runs` and `upgrade`,
and `session` to sign in with a Linear personal API key.
Start with [installation](installation.md), then [usage](usage.md). Before you connect an agent over MCP, read
[MCP](mcp.md) and [permissions](permissions.md).
